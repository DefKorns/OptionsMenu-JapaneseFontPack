
## What is this?

An optional companion to [OptionsMenu](https://github.com/DefKorns/OptionsMenu).
Adds a Japanese-capable TTF font (Noto Sans JP) so Japanese text is drawn with
the same smooth font as the other languages, instead of the built-in bitmap
font.

Requires OptionsMenu v2.0.0-alpha or newer. The pack only makes a visible
difference when the language is set to Japanese; every other language looks
the same with or without it. Safe to remove at any time - Japanese text then
falls back to the bitmap font.
