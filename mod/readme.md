
## What is this?

An optional companion to [OptionsMenu](https://github.com/DefKorns/OptionsMenu)'s
Modern UI. Drops a full Japanese-capable TTF font (Noto Sans JP, subsetted to
the same Kanji/Hiragana/Katakana OptionsMenu already supports) into place so
Modern UI renders Japanese text with the same crisp TTF rendering it already
uses for Latin languages, instead of the built-in bitmap font.

Requires OptionsMenu with Modern UI enabled and the language set to
Japanese to have any visible effect - otherwise this mod does nothing.
Safe to install even without those, and safe to remove at any time; without
it, Japanese Modern UI text simply falls back to the bitmap font it already
used before this pack existed.
